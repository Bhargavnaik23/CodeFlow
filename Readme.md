# 🚀 CodeFlow

> One place to plan, learn, code, and grow.

## 📖 About

CodeFlow is a developer productivity platform that combines:

- 📅 Smart Planner
- 📺 Course & YouTube Tracker
- 📝 Markdown Notes
- 💻 Code Playground
- 📊 Analytics
- 🔥 Study Streaks
- ⏱️ Pomodoro Timer

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- PostgreSQL
- Prisma
